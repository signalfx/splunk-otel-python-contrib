# AI underwriting pipeline -- production dependencies.
#
# Deliberately FLAT, with no `-r requirements-app.txt` include. The AgentCore starter
# toolkit uploads only a filtered build context to CodeBuild, and the included file is not
# part of it, so `uv pip install -r requirements.txt` fails inside the container with
#     error: Error parsing included file ... failed to read `requirements-app.txt`
# which reads like a dependency-resolution problem rather than a missing-file one.
# requirements-app.txt is kept alongside for local development.
#
# ORDER MATTERS. aws-opentelemetry-distro pins the whole OTel stack with `==`; installing
# it after these would silently downgrade opentelemetry-semantic-conventions beneath what
# the GenAI instrumentation needs, and the instrumentation would then fail to import at
# runtime while the process carried on serving traffic. It is deliberately absent, and the
# Splunk GenAI packages come last.
